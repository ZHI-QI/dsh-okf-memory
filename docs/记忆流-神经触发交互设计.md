# 记忆流「神经触发」交互设计

> 版本:V1 · 日期:2026-08-31
> 目标:把记忆流从"示意动画"升级为「点击记忆节点 → 神经联动触发 → 召回结果反馈」的完整交互,
> 视觉与交互模拟 AI 神经触发机制(激活扩散 spreading activation)。

---

## 1. 交互流程设计

点击一个记忆节点后,系统走一条 5 阶段状态机:`idle → 发现 → 定位 → 获取 → 反馈`,每阶段有明确状态与视觉呈现。

| 阶段 | 状态 | 触发 | 视觉呈现 | 数据动作 |
|---|---|---|---|---|
| **发现** | `discover` | 用户点击节点 | 被点节点出现脉冲闪光(白色光晕) + 四周涟漪扩散 | 读取点选节点 meta |
| **定位** | `locate` | 发现后立即 | 该节点高亮为"源/焦",周围可同步的边点亮 | 计算一级邻居(edges) |
| **获取** | `retrieve` | 定位后逐级 | **激活波沿边向邻居传递**,邻居亮起(按权重/距离延迟),远邻逐步激活 | 广度级联,取关联概念 |
| **反馈** | `feedback` | 级联收敛 | 侧栏出现「召回结果」卡片:激活动记忆列表(title/type/权重/摘要/激活强度) | 汇总激活集,供展示 |

**进度反馈**:整个过程 <1.5s;阶段切换时顶部标签亮起当前阶段名,并显示"激活了 N 个关联记忆"。

### 各阶段状态与视觉细节
- **发现**:节点短暂放大 + 白色闪光(300ms),视觉示意"信号被捕获"。
- **定位**:被点节点外圈出现环形强调色,关联边由灰变亮。
- **获取**:采用**激活扩散**——从源节点出发,沿边向邻居"打脉冲",每跳延迟 60~180ms、强度逐跳衰减(衰减系数 η≈0.6)。已激活节点保持高亮;高权重/高激活强度节点更大更亮。
- **反馈**:右侧结果面板列出激活集,按"激活强度 = 关联度 × 权重 × 衰减^跳数"排序,每条含摘要与跳数,供进一步 `okf_read`。

## 2. 触发机制(模拟神经联动)

用 **Spreading Activation(激活扩散)** 模拟神经冲动的传导:

```
激活强度 A(节点v) = Σ_边(源s→v)  A(s) × 关联权重W(s,v) × 衰减η^depth
```

- **激活顺序**:从源(0 跳)→ 1 跳邻居 → 2 跳邻居,按跳数递增,同跳内按边权/节点权重排序。
- **延迟效果**:每跳一个 activateDelay(ms),跳数越多越晚激活,形成"由近及远"的波纹感——视觉上像神经冲动逐级传导。
- **相邻传递**:一条脉冲从源节点沿一条边"射出",到达邻节点时触发该节点点燃;若该节点又被多条边激活,则取其最大强度。
- **重置**:再次点击(或切换选中)清空上次级联状态,重新触发,避免叠加混乱。

因为这是**实时画布 + rAF 驱动**,激活过程是平滑渐进的,不是瞬间渲染,天然有"联动反应"的连贯感。
`Spread-spreading 用广度优先:队列按到达时间排序,同跳内并行激发,但视觉上按 delay 错开。`

## 3. 数据流

### 数据结构(前端契约,与后端 okf_graph.json 一致)
```jsonc
{
  "nodes": [   // 记忆概念 = 神经元
    { "id":"concept-3", "title":"神经成像设备选型", "type":"TechChoice",
      "tags":["技术选型"], "description":"脑成像硬件候选", "weight":2.0, "state":"active" }
  ],
  "edges": [   // 交叉链接 = 突触
    { "source":"concept-3", "target":"method/行为-神经耦合分析" }
  ]
}
```

### 点击后处理逻辑(伪代码)
```js
function onNodeClick(id){
  state = 'discover';
  setStateUI('发现', id);
  const src = getNode(id);
  flashNode(src);                       // 发现:源闪光
  setTimeout(()=>{ state='locate'; setStateUI('定位', id); }, 220);
  setTimeout(()=>{
    state='retrieve'; setStateUI('获取', id);
    performActivation(src);             // 触发激活扩散
  }, 420);
}
function performActivation(src){
  const visited = new Set([src.id]);
  const queue = [{ n: src, depth:0, strength:1 }];
  const activations = [];
  while (queue.length){
    const { n, depth, strength } = queue.shift();
    for (const e of edgesOf(n)){
      const nb = node(e.other(n.id));
      if (visited.has(nb.id)) continue;
      visited.add(nb.id);
      const s = strength * W(e) * Math.pow(ETA, depth+1);   // 权重×衰减
      activations.push({ node:nb, strength:s, depth:depth+1 });
      pulseEdge(n, nb, depth);          // 视觉:沿边打一个脉冲
      queue.push({ n:nb, depth:depth+1, strength:s });
    }
  }
  // 获取完成 → 反馈
  activations.sort((a,b)=> b.strength - a.strength);
  setTimeout(()=> renderFeedback(activations), 900);
}
function renderFeedback(acts){
  state='feedback'; setStateUI('反馈', '激活 '+acts.length+' 个关联记忆');
  aside.innerHTML = acts.map(a=> card(a)).join('');
}
```

### 计算口径
- `W(e)=源/目标权重均值`(或 1.0) → 关联强度。
- 激活强度 = 源强度(1) × W × η^depth;η=0.6;maxDepth=2(超出只统计不渲染,防爆炸)。
- 反馈排序按激活强度降序,强度同则取权重高者前。

## 4. 可运行实现方案(关键代码结构)

### 前端标签页(React 组件,DSH client-plugin 形态)
```
src/client/NeuroGraphView.tsx      // 图谱画布 + 激活扩散
  ├─ <canvas>                       // rAF 力导向 + 激活渲染
  ├─ onNodeClick(id) → 状态机
  ├─ performActivation(src)         // BFS 激活扩散
  └─ renderFeedback(acts)          // 右侧召回结果卡片
src/client/neuro-data.ts           // 拉取 graph.json,构 nodes/edges 索引
src/client/neuro-model.ts          // 激活强度计算/排序/延迟
```
但**本次演示先跑通**:在自包含 HTML 里用纯 canvas 实现同一套状态机/BFS/激活扩散,不依赖 React,便于立即验证交互,后续再迁移进 client-plugin。

### 时序示意
```
[点击节点A]
  → 发现(源A闪光)──220ms──→ 定位(A环形高亮+邻边点亮)
  → 获取:脉冲沿 A→B→C 逐级传导(delay 递增、强度衰减)
      A(0跳,强度1) ──→ B(1跳,0.6) ──→ C(2跳,0.36) → 激活集
  → 反馈:右侧召回结果卡片(按激活强度排序)
```

### 演示验证要点
- 点击不同节点 → 触发不同级联范围(枢纽节点激活更多邻居、高权重节点激活脉冲更亮)。
- 再次点击 → 重置并重新触发,无叠加。
- 阶段名(idle/发现/定位/获取/反馈)实时更新。
